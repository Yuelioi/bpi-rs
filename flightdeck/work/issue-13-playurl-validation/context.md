# 上下文

用户明确授权读取并使用仓库根目录的 `account.toml`，仅用于 Bilibili 只读测试。不得在终端输出、测试报告、fixture、日志或提交内容中泄露 Cookie、`SESSDATA`、`bili_jct`、`buvid3` 及其他账号字段。

测试身份分为匿名、普通登录用户、会员用户三档。测试范围可覆盖全站公开可访问内容与登录/会员只读播放能力，但明确排除点赞、投币、收藏、关注、评论、发弹幕、修改账号或其他会改变远端状态的操作。

样本需要覆盖老、中、新内容，低/高画质与音质、短/长视频、单 P/多 P 等代表性类别；每组尽量使用多个样本。大规模临时采样结果放在 `target/` 或 Work references 中，不直接进入源码。只有脱敏、稳定、能锁定真实字段形态的最小 fixture 和测试才进入版本库。

当前工作树已有用户的 Flightdeck 升级改动，测试工作必须保留并绕开这些改动。任何线上响应都按不可信输入处理；测试报告只记录响应形态、计数、API 错误码和脱敏标识。
